# סנכרון קליל בין גביר לאסתי (Supabase): מה צריך לעשות

הקוד מוכן וכבוי. הנתונים נשארים ב-localStorage עד שמפעילים את הסנכרון.

## מה גביר צריך לעשות (פעם אחת, כ־10 דקות, בחינם)
1. ליצור חשבון ב-https://supabase.com (אפשר עם GitHub) ופרויקט חדש בתוכנית Free. אזור מומלץ: Frankfurt (eu-central-1).
2. ב-SQL Editor: להדביק את כל הקובץ `supabase/schema.sql` ולהריץ.
3. ב-Authentication → Sign In / Providers: לוודא ש-Email מופעל (Magic Link). אפשר לכבות הרשמה פתוחה אחרי ששניכם נרשמתם.
4. ב-Authentication → URL Configuration: Site URL וגם Redirect URL = `https://gviryamin.github.io/money-home/`
5. ב-Project Settings → API: להעתיק את Project URL ואת ה-anon public key, ולמסור אותם לבוט. לא למסור את ה-service_role key.
6. הבוט מכניס אותם ל-`config.js`, מפעיל `enabled: true` ומעלה מחדש.

## איך זה עובד אחרי ההפעלה
- כל אחד נכנס עם המייל שלו (קישור כניסה, בלי סיסמה).
- הראשון פותח משק בית ובוחר מי הוא, ומקבל קוד חד-פעמי. השני מזין את הקוד ומצטרף. אחרי זה משק הבית סגור לשניים בלבד.
- כל אחד כותב, עורך ומוחק רק את השורות שלו: הוצאות, הכנסות, תקציב אישי, תבניות והתקדמות.
- משותף לשניים: קטגוריות ותקרות הבית, קרן החירום ואישור התוכנית החודשית. שניכם יכולים לערוך אותם.
- בן הזוג רואה את ההוצאות המשותפות ואת ההכנסות. מהתקציב האישי שלך הוא מקבל רק מספר אחד, היתרה, דרך הפונקציה `partner_remaining`.
- נתוני דוגמה לא עולים לשרת לעולם.
- בסנכרון הראשון, הנתונים הקיימים בטלפון (אם אינם דוגמה) עולים לחשבון של הפרופיל המחובר.
